Descripción:  
Proyecto corresponde a una agencia de turismo ubicada
en el sur de Chile (Llanquihue) con una problemática
de organización. Se aplican principios de encapsulamiento, 
composición y herencia.
---

Estructura:  
```text
📁 src/
├── 📁 app/                        # Contiene la clase principal con el método main para iniciar la aplicación
│   └── 📄 Main.java                
└── 📁 model/                      # Contiene las clases que representan entidades u objetos
    ├── 📄 Persona.java    
    ├── 📄 Direccion.java 
    ├── 📄 Contacto.java 
    ├── 📄 Empleado.java 
    ├── 📄 GuiaTuristico.java 
    └── 📄 Transportista.java            
```
---
Instrucciones para ejecutar:  
1. Clonar el repositorio desde GitHub  
git clone https://github.com/alonsobonansco/AgenciaTurismo.git  
2. Abrir la carpeta del proyecto en Intellij desde la opción Open  
3. Ir a la clase Main, ubicada en el paquete app. Hacer click derecho en cualquier
parte del código (se abre un menú), seleccionar la opción que dice Run
(tiene un ícono de flecha de color verde)
